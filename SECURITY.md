# Security Policy

## Supported Versions

Only the latest release on `main` is supported with security fixes.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting: go to the
**Security** tab → **Advisories** → **Report a vulnerability**.
Do not open a public issue for security bugs.

## Scope

PoEMercPricer only reads the clipboard and takes screenshots — it never
reads or writes game memory. ToS/anti-cheat concerns are therefore out
of scope for security reports, but are welcome as normal issues.
